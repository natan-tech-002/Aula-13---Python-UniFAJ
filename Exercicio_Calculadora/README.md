# Calculadora de terminal em Python

Uma calculadora simples para praticar funções, entrada de dados, condicionais, tratamento de erros e operações matemáticas.

## ✨ Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Entrada de números inteiros ou decimais.
- Aceita vírgula ou ponto como separador decimal.
- Valida entradas inválidas.
- Trata a tentativa de divisão por zero.
- Não depende de bibliotecas externas: usa módulos da biblioteca padrão do Python.

## ▶️ Como executar

Tenha o Python 3.10 ou superior instalado. Na pasta raiz do repositório, execute:

```bash
python Exercicio_Calculadora/calculadora.py
```

No Windows, se o comando `python` não estiver configurado, tente:

```powershell
py Exercicio_Calculadora/calculadora.py
```

## 🧪 Exemplo de uso

```text
Escolha uma operação:
  1 - Adição (+)
  2 - Subtração (-)
  3 - Multiplicação (*)
  4 - Divisão (/)
  0 - Sair
Opção: 1
Digite o primeiro número: 10
Digite o segundo número: 2

Adição (+): 10 e 2
Resultado: 12
```
